ThreadShelf organizes your digital life. It connects to various AI services to pull your history into a single, searchable local database.

## 📋 Frequently Asked Questions

### Does the app send my chats to a third party?
No. The app uses your local hardware to store and process data. Your files remain on your computer at all times.

### Can I search through years of history?
Yes. The local database indexer handles thousands of conversations. The search tool returns results in milliseconds.

### Do I need to be a programmer to use this?
No. The software works out of the box. You do not need to write code. You do not need to install extra software like Python or Node.js.

### How do I connect my accounts?
The settings menu provides a clear interface for each service. You enter your API key or follow the prompt to link your provider account. The app stores these keys locally in your secure Windows vault.

### What happens if I lose my internet connection?
The app remains functional offline. You view and search your archive without a connection. You only need the internet when you want to import new chats from your providers.

## 🔧 Troubleshooting

If the application does not open, check if your antivirus software flagged the installer. You may need to click "Run anyway" if Windows presents a security warning. This happens because the software is new. 

If the app fails to import chat history, check your login details in the settings menu. Make sure your API keys are valid. Contact your AI service provider if you cannot generate a successful connection.
